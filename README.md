# README.md

## Online Retail Analysis

This project analyzes transactional sales data from a UK-based online retail company between 2009 and 2011.

The goal of the project is to extract business insights related to:

* Customer purchasing behavior
* Country performance
* Monthly sales trends
* Order patterns
* Revenue concentration

The analysis was performed using Python, Pandas, and Matplotlib.

# Dataset

Dataset source:

[Kaggle Online Retail Dataset](https://www.kaggle.com/datasets/lakshmi25npathi/online-retail-dataset?resource=download)

The dataset contains over 1 million retail transaction records including:

* invoices
* products
* quantities
* prices
* customer IDs
* countries
* transaction timestamps

# Key Metrics

* Total Revenue: £17.7M+
* Total Orders: 36,975
* Average Order Value (AOV): £479.88
* Units Per Transaction (UPT): 289.95

---

# Main Insights

* Revenue is heavily concentrated in the United Kingdom.
* A small number of customers contribute a large portion of total revenue.
* Purchasing behavior strongly suggests wholesale activity.
* Sales trends show strong seasonal peaks.
